4. Mandatory Quality & Review Governance Rules

Git & PR Protocols

  • Direct commits to main are forbidden[cite: 38]. Work strictly on assigned branches (e.g., feature/conv2d)[cite: 38, 50].
  • No Self-Merging: Developers cannot merge their own code[cite: 38, 50]. The assigned supervisor must inspect the code, verify unit tests, and approve the PR[cite: 38, 50].
  • Frank merges approved PRs; Peter audits integrated builds for memory safety and risk[cite: 38, 50].

AI Usage & README Rules

  • AI tools may only serve as supporting aids; AI must not generate the whole project[cite: 38, 53].
  • Every member must log tool name, purpose, and technical justification in weekly reports[cite: 38, 53].
  • The project README.md and C++ logic must be original engineering work[cite: 38, 53].
